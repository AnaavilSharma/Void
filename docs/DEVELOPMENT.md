# Development Notes

## Project structure

The application separates the Django backend from the React frontend and uses a small startup script to run the development services together.

## Local development

Use isolated Python and Node environments, keep local credentials in environment variables, and avoid committing generated files such as virtual environments, build output, logs, or macOS metadata.

## Project status

Void is a development project and should be treated as a foundation for further product work rather than a production deployment without additional testing and hardening.
